# 화면 목록

## 구현된 1차 화면

- 로그인
- 메인 현황판
- 정비의뢰 접수
- 정비건 목록
- 정비건 상세
- 관리자 배정/target/승인/반려
- 정비사 작업 시작/완료보고
- target 달력
- KPI 대시보드
- 관리자 설정
- 엑셀 다운로드

## 확장 예정 화면

- 정비건 중복 의심 전용 화면
- 사업장/고객사 관리
- 장비 Master List 관리
- 고장유형 관리
- Priority 기준 관리
- 외주업체 관리
- 외주 KPI 상세
- KPI 제외건 관리 전용 화면
- 업무일지 자동생성 상세 화면
- 알림 센터
- 백업/복구 관리자 화면

현재 구현은 모든 핵심 workflow가 동작하는 통합 화면 중심이며, 운영 중 사용 빈도와 현장 피드백을 보며 전용 화면으로 분리할 수 있다.
