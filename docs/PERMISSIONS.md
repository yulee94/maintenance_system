KPI와 관리자 API는 프론트엔드 메뉴 숨김만으로 처리하지 않고 서버 라우트에서 role을 다시 검사한다.

일반 관리자는 운영 사용자 관리는 가능하지만 `ADMIN`, `EXECUTIVE`, `SUPER_ADMIN` 같은 상위 권한 부여는 할 수 없다. 상위 권한 부여와 최고 관리자 계정 수정/비활성화는 고민서 책임 같은 `SUPER_ADMIN`만 가능하다.
