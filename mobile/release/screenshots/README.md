# Store Screenshots

`mobile/release/screenshots/ko-KR` 폴더는 App Store와 Google Play 제출용 스크린샷 초안입니다.

현재 포함되는 이미지는 심사 준비용 초안이며, 정식 제출 직전에는 실제 staging 빌드를 iOS/Android 기기 또는 에뮬레이터에서 캡처한 최종 이미지로 교체합니다.

권장 제출 컷:

- 로그인 및 테스트 계정 선택
- 오늘 업무와 긴급/완료 현황
- 정비건 상세와 완료보고
- AI 정비 문의와 권한 제한
- 관리자 승인/KPI 보고

권장 크기:

- iOS 6.7형: 1290 x 2796
- Android phone: 1080 x 1920 이상
