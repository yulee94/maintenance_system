# 권한 사용 사유

## 푸시 알림

작업 배정, 승인 요청, 공지사항, 장애 알림, 입고/출고, 예약, 결제/정산 업무 알림을 받기 위해 사용합니다.

## 카메라

정비 완료보고 작성 시 장비 상태, 고장 부위, 교체 부품, 조치 완료 상태를 촬영해 보고서에 첨부하기 위해 사용합니다.

## 사진 보관함

현장에서 이미 촬영한 사진 또는 동영상을 정비 완료보고에 첨부하기 위해 사용합니다.

## 위치

현재 모바일 앱은 위치 권한을 요청하지 않습니다. 향후 출퇴근, 방문 인증, 장비 위치 확인 기능을 추가할 경우 별도 고지와 동의, 개인정보 처리방침 반영, 위치정보 관련 법적 검토 후 적용합니다.

## 결제

현재 모바일 앱은 소비자 대상 인앱 결제, 디지털 콘텐츠 판매, 카드번호 입력, 결제수단 등록 기능을 제공하지 않습니다. 결제/정산 알림은 내부 업무 알림입니다.
